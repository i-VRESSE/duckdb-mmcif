# EMDB archive fixture

`emd-4404.cif.gz` is the unmodified experimental-metadata CIF downloaded from
[EMDB entry EMD-4404](https://www.ebi.ac.uk/emdb/EMD-4404/) on 2026-10-10:

https://ftp.ebi.ac.uk/pub/databases/emdb/structures/EMD-4404/metadata/emd-4404.cif.gz

SHA-256: `57884004621831e6cf03c72757db38322e580f6b4bce60ea7b1f00b93852d75b`.

It describes the eIF2B:eIF2 complex, phosphorylated on eIF2 alpha serine 52.
The archive metadata declares PDBx/mmCIF dictionary version 5.398; its EM
categories are supported by the bundled current base dictionary. The standalone
3DEM dictionary's shared definitions retain current base types and URLs.

The real values `3-174` in `_em_3d_fitting_list.pdb_chain_residue_range` and
`2-48` in `_em_image_scans.used_frames_per_image` exposed the old mapping of
`int-range` to `BIGINT`. The regression test scans both full categories and
checks that ranges remain text while scalar numbers remain numeric.
